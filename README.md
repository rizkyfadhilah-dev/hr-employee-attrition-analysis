# HR Employee Attrition Analysis

Analysis of employee attrition using Python, SQL, Pandas, and Matplotlib.

## Project Overview

This project analyzes employee attrition data to identify patterns and factors associated with employee turnover.

The analysis combines data cleaning, exploratory data analysis (EDA), SQL analysis, and data visualization.

## Dataset

The dataset contains **1,470 employee records** and **35 original columns**.

After data cleaning, three constant columns were removed, resulting in **32 columns**.
